## Maquina Expendedora en C# 🥤

Este es un proyecto escolar desarrollado en c# que simula el funcionamiento de una maquina expendedora de sodas

## Caracteristicas
- Catalogo de 5 bebidas con diferentes precios.
- Validacion de stock (Si una bebida se agota no se puede comprar).
- Validacion de saldo (No puedes comprar si no tienes dinero suficiente).
- Interfaz de consola interactiva.

## Como ejecutar el programa
1.- Necesitas tener instalado el SDK de .NET o un commpilador de C#.
2.- Descargar el archivo ´MaquinaExpendedora.cs´.
3.- Ejecuta el codigo en tu entorno de desarrollo (Visual Studio, VS Code o Compiladores en linea).
